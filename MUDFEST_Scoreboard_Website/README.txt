MUDFEST Scoreboard Tally

Open index.html in a modern browser.

Features:
- Separate Class 2 Pro-Stock and Kids tables
- Best Time, Penalties, Final Time
- Adult Scale Points
- DNF and DQ always treated as infinite time and sorted to the bottom
- Sort by final time, scale points, or name
- LocalStorage persistence
- Excel-compatible .xls export with separate Adult and Kids sheets

Time formats accepted:
- 1:23.456
- 83.456

Important: LocalStorage is tied to the specific browser/device. Clearing browser site data will remove saved scoreboard data.
