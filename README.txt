MUDFEST EVENT WEBSITE
=====================

Files:
- index.html
- styles.css
- script.js

Place all media files in the SAME folder as index.html using these exact names:

Main banner:
- banner.jpg

Sponsors:
- sp1.jpg to sp10.jpg

Venue:
- entrance.webp
- entrance.jpg
- parking.jpg
- parts.jpg

Highlights:
- s1.jpg to s20.jpg

Videos:
- cmb-low.mp4
- k-bro-low.mp4

To preview:
1. Put all images and videos inside this folder.
2. Open index.html in a browser.

For GitHub Pages:
1. Upload all files to a GitHub repository.
2. Open repository Settings > Pages.
3. Deploy from the main branch and root folder.
